# SpotHunt


Explore, Befriend, Compete



Aplicatiile de social media si short form content tin tinerii in casa, ceea ce duce la singuratate si un stil de viata nesanatos.

## Obiective 

Promovarea culturii locale
Promovarea unui stil de viata sanatos
Socializare face to face

## Cum functioneaza?

Statuile, monumentele si cladirile istorice apar in aplicatie ca Spoturi.

Utilizatorii primesc puncte cand viziteaza Spoturi si concureaza cu prietenii lor!
